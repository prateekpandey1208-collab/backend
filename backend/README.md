# Intro to Backend

A learning project based on Shivani's freeCodeCamp backend tutorial.

Original source:
https://github.com/NewSmoke38/intro-to-backend

## Technologies

- Node.js
- Express
- MongoDB and Mongoose
- Bcrypt

## Run locally

1. Run npm install.
2. Create .env in the main project folder.
3. Add PORT and MONGODB_URI.
4. Run npm run dev.
5. Open http://localhost:4000.

## Features

- Register users with hashed passwords
- Check login credentials
- Demonstrate a logout response
- Create, read, update and delete posts

This learning project does not create login sessions or protect post routes.
